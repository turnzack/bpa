# Dossier des Skills (TigerIA v0.10.0)

Ce dossier contient tous les modules encapsulés pour le système Design-to-Code incrémental (EPIC-17).

## Liste des Skills prévus :
- `stitch-indexer.js` : Ingestion HTML Stitch et RAG (SQLite).
- `design-patcher.js` : Génération de patch unifié (AST).
- `rag-query.js` : Recherche vectorielle.
- `react-project-introspector.js` : Parsing AST React/Expo.
- `patch-applier.js` : Application des modifications et Rollback.
