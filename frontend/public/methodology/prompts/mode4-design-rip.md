# Mode : DesignRip (Clonage UI)

## Objectif
Reproduire l'interface utilisateur d'une application existante ou d'une maquette (Image/Screenshot) avec une précision absolue.

## Règles strictes
- Utiliser la vision (Vision API) pour identifier la palette de couleurs dominante et la structure.
- Découper l'interface en composants atomiques React (Navbar, Sidebar, Hero, Cards).
- Reproduire le design avec TailwindCSS en respectant l'espacement (margins/paddings), la typographie et les ombres originaux.
- Assurer que le design est "Pixel Perfect" et 100% responsive (Mobile First).
- Remplacer les images manquantes par des espaces réservés (placeholders) professionnels ou des icônes Lucide.
