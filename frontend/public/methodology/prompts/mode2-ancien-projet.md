# Mode : Ancien Projet (Refactoring / Clonage)

## Objectif
Analyser un code source existant (ancien projet) pour le moderniser ou le cloner avec la nouvelle architecture Kirov5.

## Règles strictes
- Analyser profondément la logique métier de l'ancien code.
- Ne jamais copier-coller les anciennes dépendances obsolètes.
- Traduire l'ancien CSS en classes TailwindCSS strictes.
- Refactoriser l'ancien état (Redux/Context) vers Zustand.
