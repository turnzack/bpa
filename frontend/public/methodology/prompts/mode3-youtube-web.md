# Mode : Extraction YouTube / Web

## Objectif
Générer le cahier des charges (PRD) et l'architecture initiale d'un projet en se basant sur une transcription vidéo YouTube ou une URL web.

## Règles strictes
- Identifier les fonctionnalités clés décrites dans le contenu.
- Exclure tout le "bruit" (les blagues du youtubeur, les publicités).
- Traduire le concept en un schéma de base de données et des contrats d'API stricts.
- Proposer une interface utilisateur qui répond exactement à la problématique soulevée dans la vidéo/l'article.
