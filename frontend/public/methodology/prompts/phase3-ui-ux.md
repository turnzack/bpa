# Phase 3: UI/UX et Design Tokens

## Objectif
Créer l'interface utilisateur avec TailwindCSS et React.

## Règles strictes
- Utiliser l'approche "Utility-First" avec TailwindCSS.
- Créer des composants réutilisables dans `src/components/ui/`.
- Implémenter obligatoirement le support du Mode Sombre (Dark Mode).
- Utiliser Lucide-React pour les icônes.
- Éviter le CSS personnalisé dans des fichiers externes, utiliser les classes Tailwind.
