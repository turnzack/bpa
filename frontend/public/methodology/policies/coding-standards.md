# Coding Standards Kirov5 (Grade Gold)

1. **TypeScript Obligatoire** : Le type `any` est banni. Tout doit être typé avec précision.
2. **Architecture** : Séparation stricte de la vue (React) et de la logique (Zustand/Services).
3. **Nommage** : CamelCase pour les variables/fonctions, PascalCase pour les composants React et les Types/Interfaces.
4. **Gestion des erreurs** : Afficher des messages clairs à l'utilisateur lors de défaillances (Toast/Alertes).
